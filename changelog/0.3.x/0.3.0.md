# 0.3.0 — 2026-11-13

## Added

- Add the transitland-guide skill resource for station departures and feed discovery.
- **Exact feed lookup** accepts an Onestop ID or a positive internal ID in `transitland_find_feeds` and combines it with other filters, including operator membership. ([#19](https://github.com/cyanheads/transitland-mcp-server/issues/19))
- **Service alerts** appear for the queried stop and its returned children and on affected departure rows. Stop alerts are available even when no departures are returned. ([#23](https://github.com/cyanheads/transitland-mcp-server/issues/23))

## Changed

- **Packaging** ships the guide in npm, Docker, plugin, and desktop installs, adds Agent Plugins manifests, and forwards the exported Transitland key through the Codex overlay.
- **Build tooling** targets Bun 1.4.4 and synchronizes the development checks, release scripts, and framework skills.

## Fixed

- **Stop discovery** resolves parent stations and exposes platform codes and descriptions. A failed optional parent lookup leaves the stop page available with a notice. ([#13](https://github.com/cyanheads/transitland-mcp-server/issues/13))
- **Exact stop and route filters** resolve internal IDs while retaining the other filters. Operator lookups require an Onestop ID and verify the returned identity. ([#14](https://github.com/cyanheads/transitland-mcp-server/issues/14), [#24](https://github.com/cyanheads/transitland-mcp-server/issues/24))
- **Station departures** merge and order station and child departures before applying the limit and identify the boarding platform on each row. Dated queries honor the GTFS service day and accept overnight windows. ([#15](https://github.com/cyanheads/transitland-mcp-server/issues/15), [#16](https://github.com/cyanheads/transitland-mcp-server/issues/16))
- **Operator feed discovery** applies search and fetch-error filters before limiting results and reports when a cursor was ignored. ([#17](https://github.com/cyanheads/transitland-mcp-server/issues/17))
- **Feed URLs and terms** include GBFS and MDS discovery URLs, share-alike terms, and attribution instructions. The fetch timestamp describes the selected feed version. ([#18](https://github.com/cyanheads/transitland-mcp-server/issues/18))
- **Geographic searches** validate bbox coordinates locally, allow point and box filters to intersect, and point callers to `openstreetmap_search_places`. ([#20](https://github.com/cyanheads/transitland-mcp-server/issues/20), [#21](https://github.com/cyanheads/transitland-mcp-server/issues/21))
- **Pagination notices** distinguish an exhausted continuation from an empty first page and explain how to request the next page. ([#22](https://github.com/cyanheads/transitland-mcp-server/issues/22))
- **Text results** preserve literal upstream values alongside the structured output.
