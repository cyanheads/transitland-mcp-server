# 0.3.1 — 2026-11-20

## Fixed

- **Departures** combine and sort rows from all returned matching stops. Stop discovery and departure platforms expose source identifiers for feed-scoped lookups using `<feedOnestopId>:<stopId>`. ([#27](https://github.com/cyanheads/transitland-mcp-server/issues/27))
- **Station coverage** reports when Transitland reaches its 100-child-record limit and directs callers to query individual platforms. ([#28](https://github.com/cyanheads/transitland-mcp-server/issues/28))
- **Departure limits** flag truncation only when rows are omitted and advise callers to raise the limit or narrow the window. ([#30](https://github.com/cyanheads/transitland-mcp-server/issues/30))

## Changed

- **Vitest** uses worker threads for Bun compatibility.
