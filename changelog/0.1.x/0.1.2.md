# 0.1.2 — 2026-09-20

## Changed

- **HTTP sessions default to stateless** (#6) — no tool holds per-session state or calls `ctx.requestInput`, so `createApp()` declares `sessionMode: 'stateless'` and drops the session store; `MCP_SESSION_MODE` still overrides when set to a meaningful value.
- **An invalid tool call now classifies as `InvalidParams` (-32602)**, not `ValidationError`, with a schema-derived `Recovery: …` hint appended to the error text.
- **A tool call tolerates extra keys, common key-name aliases, and a JSON-stringified array argument** before failing validation, instead of rejecting outright.
- **Upstream error responses no longer forward their request URL to callers by default** — a query string can carry an API key or other identifiers.
